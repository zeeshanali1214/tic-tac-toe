# Tic-Tac-Toe

A two-player Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features
- 3 × 3 clickable board, players alternate X and O
- Filled cells cannot be selected again
- Detects wins (rows, columns, diagonals) and highlights the winning cells
- Displays a draw message when the board is full
- Restart Game button
- Responsive design

## Run locally
Open `index.html` in any browser.

## Deploy on GitHub Pages
1. Upload all files to a GitHub repository (`index.html` must be in the root).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Your game will be live at `https://<your-username>.github.io/<repo-name>/`.
